Hệ thống đã được đóng gói thành bộ cài đặt portable, không cần cài đặt Python thủ công. 
Để chạy chương trình, vui lòng làm theo các bước sau:

1. GIẢI NÉN
   - Giải nén toàn bộ thư mục 'LighthouseOCR' ra ổ cứng (Ví dụ: D:\LighthouseOCR).

2. THIẾT LẬP MÔI TRƯỜNG (CHỈ CHẠY 1 LẦN DUY NHẤT)
   - Vào thư mục 'LighthouseOCR'.
   - Tìm file 'Setup_Moi_Truong.bat'.
   - Chuột phải vào file này và chọn "Run as Administrator" (Chạy với quyền Quản trị).
   - Đợi chương trình tự động tải Python portable và các thư viện AI (Khoảng 2-5 phút tùy mạng).
   - Khi hiện thông báo "HE THONG DA SAN SANG!", bạn có thể đóng cửa sổ đó lại.

3. CHẠY CHƯƠNG TRÌNH
   - Chạy file 'LighthouseOCR.exe' để mở giao diện chính.
   - Lần đầu chạy, hãy vào biểu tượng Settings (Bánh răng) để nhập Gemini API Key.

4. CÁC LƯU Ý QUAN TRỌNG:
   - Dữ liệu Master List: Nằm trong thư mục 'Data structure'. Hãy đảm bảo các file Excel trong đó luôn đúng định dạng.
   - File kết quả: Sẽ được lưu trong thư mục 'DONE' nằm cùng cấp với thư mục ảnh đầu vào mà bạn chọn.
   - Internet: Cần có kết nối Internet để gọi API Gemini và để chạy file Setup lần đầu.
